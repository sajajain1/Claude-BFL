# ModernizeAI REST API

Base URL: `http://localhost:8080`. All error responses share one shape:

```json
{ "timestamp": "2026-10-12T07:30:00Z", "status": 422, "code": "UNSAFE_ARCHIVE", "message": "Unsafe path in archive: '../evil.java' attempts directory traversal." }
```

`message` is always safe to show to users. Unexpected errors return `INTERNAL_ERROR` with a generic message; details go only to server logs.

## Health and status

| Method | Path | Description |
|---|---|---|
| GET | `/actuator/health` | Liveness/readiness (Spring Boot Actuator). Also `/actuator/health/liveness`, `/actuator/health/readiness`. |
| GET | `/api/health` | `{"status":"UP","service":"modernizeai-backend"}` |
| GET | `/api/ai/status` | `{"configured":false,"model":"claude-opus-5-5","message":"..."}`. `configured` only means a key is present; no API call is made. |
| GET | `/api/limits` | Upload limits and supported target versions for the UI. |

## Analyze a project

`POST /api/analyses` with `multipart/form-data`:

| Part / param | Required | Notes |
|---|---|---|
| `file` | yes | `.zip` of a Maven project, max 20 MB |
| `targetJavaVersion` | no | `17` (default) or `21` |

```bash
curl -F file=@samples/legacy-shop.zip -F targetJavaVersion=17 http://localhost:8080/api/analyses
```

Errors: `400 INVALID_UPLOAD` (missing file, not `.zip`, not a ZIP, empty, corrupt), `400 VALIDATION_FAILED` (bad `targetJavaVersion`), `413 UPLOAD_TOO_LARGE`, `422 UNSAFE_ARCHIVE` (path traversal, absolute paths, too many entries, zip bomb), `422 NOT_A_MAVEN_PROJECT` (no `pom.xml`). ## Retrieve and export

Reports are kept **in memory** for 60 minutes (max 50); a restart clears them.

| Method | Path | Response |
|---|---|---|
| GET | `/api/analyses/{id}` | `AnalysisReport` (`404 ANALYSIS_NOT_FOUND` if expired/unknown, `400` if id is not a UUID) |
| GET | `/api/analyses/{id}/report.json` | Same JSON as an attachment download |
| GET | `/api/analyses/{id}/report.md` | Markdown report, including any Claude explanations generated so far |

## Claude explanations

`POST /api/analyses/{id}/explanations` with JSON body:

```json
{ "findingIds": ["F-001", "F-006"] }
```

- 1–5 ids per request (ids must match `F-\d+` and exist in the report).
- Already-explained findings are served from the in-memory cache without a new API call.

**200 OK**

```json
{
  "analysisId": "…",
  "model": "claude-opus-5-5",
  "explanations": [
    {
      "findingId": "F-006",
      "whyItMayOccur": "…",
      "minimalFix": "…",
      "compatibilityNotes": "…",
      "missingContext": ["…"],
      "confidence": "medium"
    }
  ],
  "notice": "Generated by Claude from limited snippets. AI output can be wrong or incomplete; verify …"
}
```

| Status | Code | Meaning |
|---|---|---|
| 400 | `VALIDATION_FAILED` / `UNKNOWN_FINDING` / `MALFORMED_REQUEST` | Bad request body |
| 404 | `ANALYSIS_NOT_FOUND` | Report expired |
| 502 | `AI_RESPONSE_INVALID` | Claude answered but the JSON failed validation; nothing is shown or cached |
| 503 | `AI_NOT_CONFIGURED` | `ANTHROPIC_API_KEY` not set |
| 503 | `AI_AUTH_FAILED`, `AI_RATE_LIMITED`, `AI_MODEL_NOT_FOUND`, `AI_REQUEST_REJECTED` (e.g. no credit), `AI_UPSTREAM_ERROR`, `AI_UNREACHABLE`, `AI_REFUSED` | Upstream problems, reported honestly |
